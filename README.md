# Samsun Mobilya

**Canlı site:** [samsunmobilya.tr](https://samsunmobilya.tr/)

Samsun Mobilya’nın mimari tasarım, iç mimari, doğal ahşap ve özel ölçü mobilya çalışmalarını tanıtan kurumsal web projesi. Hizmet ve mobilya sayfaları, katalog, iletişim, yerel SEO ve PWA deneyimi içerir.

Bu depo yalnızca proje tanıtımı içindir. Kaynak kodu, yönetim paneli kodu, erişim bilgileri ve müşteri verileri paylaşılmamaktadır.
